PRECIFICADOR DE PEÇAS — macOS — VERSÃO 1.1.1

PRIMEIRA INSTALAÇÃO
1. Instale Python 3.12 para macOS em https://www.python.org/downloads/macos/
   O instalador universal2 atende Macs Apple Silicon e Intel.
2. Extraia o pacote e mantenha todos os arquivos juntos.
3. Abra iniciar.command. A primeira execução prepara as bibliotecas e o modelo.
4. Mantenha o Terminal aberto. O programa abre no navegador em
   http://127.0.0.1:8501. Para encerrar, pressione Control+C no Terminal.

Se o Finder não executar o arquivo, abra o Terminal na pasta extraída e rode:
    bash iniciar.command

PARA ATUALIZAR O MAC JÁ INSTALADO
1. Encerre o servidor antigo com Control+C, se ainda estiver rodando.
2. Copie estes arquivos do pacote para a pasta atual do programa, substituindo:
   app.py
   services/local_ui.py (dentro da pasta services existente)
   iniciar.command
3. Preserve sua pasta .venv, seu .env, suas fotos e os resultados.
4. No Terminal dessa pasta, execute:
    bash iniciar.command
   As dependências já instaladas serão reaproveitadas. Confirme Versão 1.1.1.

CORREÇÃO DOS SELETORES
No macOS, selecionar pasta ou planilha usa o seletor do sistema em um processo
separado. Tkinter não é aberto na thread do Streamlit, evitando o encerramento
"NSWindow should only be instantiated on the main thread".
Se o seletor não estiver disponível, digite o caminho completo no campo.

Watchdog é opcional. O aviso para instalá-lo não é a causa dessa falha.
Os nomes padronizados e o Excel de cinco colunas são iguais aos do Windows.
O programa requer Python; o pacote não é um aplicativo .app independente.
