PRECIFICADOR DE PEÇAS — VERSÃO 1.2.0

MAC
Requer macOS 13 Ventura ou posterior (Intel ou Apple Silicon) e Python 3.12.
Extraia o pacote Mac e execute iniciar.command. Alternativa no Terminal,
dentro da pasta extraída: bash iniciar.command. Leia LEIA_ME_MAC.txt.

WINDOWS
Requer Python 3.12 de 64 bits, com pip, launcher py e Tcl/Tk.
Extraia o pacote Windows e execute iniciar.bat. Leia LEIA_ME_WINDOWS.txt.

Mantenha o Terminal/janela de comandos aberto enquanto usar o programa.
Os iniciadores verificam as versões das bibliotecas, instalam/atualizam quando
necessário e preparam o modelo local. Não copie .venv entre sistemas.

DADOS E ATUALIZAÇÃO
Preserve .env, fotos e resultados. Ao atualizar, copie os arquivos de código,
requirements.txt, check_dependencies.py e o iniciador do seu sistema.
No aplicativo, informe a chave Gemini, selecione as fotos e confira a sequência.
Selecione sua planilha existente para trabalhar em uma cópia local.

MERCADO LIVRE
Conexão opcional. Use App ID e Client Secret da mesma aplicação.
O retorno precisa ser uma página HTTPS publicada e salva no portal.
A página oauth-retorno/retorno.html está incluída para hospedagem estática;
confirme que a URL abre antes de cadastrá-la. Leia oauth-retorno/README.md.
No portal e no programa, mantenha a mesma URI e configuração de PKCE.

Autorize no site oficial e use Copiar retorno para concluir no programa.
Se a troca de token for recusada, a interface mostra HTTP/código OAuth
reconhecido sem exibir segredos. A conexão só é confirmada quando a interface
informa Conta conectada. A autorização não garante acesso à busca de concorrentes.

O programa requer Python; os ZIPs não são executáveis .app/.exe independentes.
Leia README.md e VALIDACAO.md para detalhes e limites da validação.
