# Pacotes 1.1.1

- [Mac — baixar ZIP](https://github.com/gabrieelmoraess171/mercadao-ia-tabela/raw/refs/heads/main/downloads/precificador-mac-1.1.1.zip): extraia e abra `iniciar.command`, ou execute `bash iniciar.command` no Terminal dentro da pasta extraída. Consulte `LEIA_ME_MAC.txt` para atualizar uma instalação existente.
- [Windows — baixar ZIP](https://github.com/gabrieelmoraess171/mercadao-ia-tabela/raw/refs/heads/main/downloads/precificador-windows-1.1.1.zip): extraia e abra `iniciar.bat`. Consulte `LEIA_ME_WINDOWS.txt`.

Os pacotes incluem o código e o iniciador para cada sistema. Requerem Python 3.12. Não incluem credenciais, bibliotecas instaladas, fotos ou planilhas de estoque.

Os ZIPs correspondem à versão 1.1.1 do código, commit `e49063f`. Alterações posteriores no repositório não modificam esses pacotes automaticamente.
